# MADMEN - 双人合作弹幕射击游戏架构设计文档

## 1. 项目概述

### 1.1 项目信息
| 项目 | 内容 |
|:-----|:-----|
| **游戏名称** | MADMEN |
| **游戏类型** | 第三人称追尾视角双人合作弹幕射击游戏 |
| **引擎** | Godot 4.x (GDScript/C#) |
| **目标平台** | PC (Steam) |
| **支持模式** | 本地双人分屏 |

### 1.2 核心玩法
两名玩家分工合作：
- **驾驶员(P1)**：驾驶机车躲避路面障碍，释放机车技能
- **射击手(P2)**：控制射击角度，击落空中无人机和弹幕

---

## 2. 架构设计原则

### 2.1 核心原则
- **高内聚**：每个模块职责单一，逻辑紧密相关
- **低耦合**：模块间通过接口通信，依赖注入
- **可扩展**：方便添加新武器、新敌人、新关卡
- **可测试**：业务逻辑与表现层分离

### 2.2 设计模式应用
| 模式 | 应用场景 |
|:-----|:---------|
| **信号(Signal)** | Godot内置信号机制用于模块间通信 |
| **单例(AutoLoad)** | 全局管理器(游戏状态、音频、配置) |
| **工厂模式** | 敌人生成、道具生成 |
| **状态机** | 玩家状态、BOSS状态、游戏状态 |

### 4.2 单例层 (Autoload)

#### GameManager.gd - 游戏总管理器
```gdscript
# 职责：管理游戏主状态、全局游戏逻辑
# 接口：
#   - start_game() / pause_game() / resume_game() / end_game()
#   - get_game_state() -> GameState
#   - emit_signal("game_state_changed", state)
```

#### InputManager.gd - 输入管理器
```gdscript
# 职责：统一管理玩家输入，映射到具体操作
# 接口：
#   - get_driver_input() -> DriverInputData
#   - get_shooter_input() -> ShooterInputData
#   - is_action_pressed(action, player_id)
```

#### AudioManager.gd - 音频管理器
```gdscript
# 职责：管理所有音频播放
# 接口：
#   - play_sfx(sfx_name)
#   - play_bgm(bgm_name, fade=true)
#   - set_volume(category, value)
```

### 4.3 核心层 (Core)

#### EventBus.gd - 事件总线
```gdscript
# 职责：模块间解耦通信
# 使用方式：
#   EventBus.enemy_killed.connect(_on_enemy_killed)
#   EventBus.emit("enemy_killed", enemy, damage_dealer)
```

#### ObjectPool.gd - 对象池
```gdscript
# 职责：高效管理子弹、敌人、道具等对象的创建销毁
# 接口：
#   - get_object(pool_name, scene_path) -> Node
#   - return_object(pool_name, instance)
```

#### DamageSystem.gd - 伤害计算
```gdscript
# 职责：统一的伤害计算逻辑
# 接口：
#   - calculate_damage(base_damage, modifier) -> float
#   - apply_damage(target, damage_info)
#   - calculate_elemental_damage(source, target, element)
```

## 6. 通信机制

### 6.1 信号通信 (EventBus)

```gdscript
# 定义全局信号
class_name EventBus
extends Node

# 战斗信号
signal enemy_killed(enemy, killer)
signal bullet_hit(target, bullet, damage)
signal player_damaged(player, damage)

# 游戏信号
signal segment_completed(segment_id)
signal world_state_changed(from_state, to_state)
signal role_swapped(driver_id, shooter_id)

# 经济信号
signal item_picked_up(item, picker)
signal coin_collected(amount)
signal shop_purchased(item_id, cost)

# 追兵信号
signal vehicle_breakdown()
signal repair_progress_changed(progress)
signal chase_caught()
```

### 6.2 直接引用 (必要时使用)

```gdscript
# 通过依赖注入获取引用
class_name CombatSystem
extends Node

var _spawn_system: SpawnSystem
var _damage_system: DamageSystem

func _ready():
    _spawn_system = EventBus.get_node("/root/SpawnSystem")
    _damage_system = EventBus.get_node("/root/DamageSystem")
```

| 修饰符 | 含义 | Godot实现 |

## 10. 扩展性设计

### 10.1 新增武器

1. 在 `weapon_stats.json` 添加武器配置
2. 继承 `WeaponBase` 创建新武器类
3. 在 `WeaponFactory` 注册武器
4. 添加对应音效和视觉资源

### 10.2 新增敌人

1. 在 `enemy_stats.json` 添加敌人配置
2. 继承 `EnemyBase` 创建新敌人类
3. 在 `SpawnSystem` 注册敌人生成规则
4. 添加对应视觉资源

### 10.3 新增路段

1. 在 `SegmentGenerator` 添加路段生成逻辑
2. 配置敌人波次和密度
3. 添加特殊机制(如有)
