# 美术资源对接规范

> 程序员与美术沟通用，版本：v1.0

---

## 基础要求

| 项目 | 要求 |
|------|------|
| 文件格式 | PNG（重要物件带透明通道） |
| 色彩空间 | sRGB |
| 命名 | `{类型}_{名称}_{状态序号}.png` |
| 导出 | 最高质量，无压缩 |

---

## 尺寸规格

### 角色精灵
- 主角：256x256px 或 512x512px
- 敌人：128x128px 或 256x256px
- BOSS：512x512px 或 1024x1024px

### 动画帧数
| 动作 | 帧数 | 帧率 |
|------|------|------|
| 待机 | 2-4帧 | 8 FPS |
| 移动 | 6-8帧 | 12 FPS |
| 攻击 | 4-6帧 | 16 FPS |
| 受伤 | 2-3帧 | 24 FPS |

### UI资源
- 图标：64x64px / 128x128px
- 按钮：128x256px
- 面板背景：1920x1080px（考虑9宫格）

### 场景
- 瓦片：64x64px / 128x128px（2的幂次方）
- 背景图：512x512px 起，最大 2048x2048px

---

## 命名示例

```
player_idle_01.png      # 玩家待机帧
player_run_01.png       # 玩家移动帧
enemy_slime_attack_01.png  # 史莱姆攻击帧
ui_btn_start_normal.png  # 开始按钮-正常态
ui_btn_start_pressed.png # 开始按钮-按下态
```

## 提交流程

1. 按上述目录结构放置文件
2. 确保命名规范
3. 有方向区分的角色提供 **WASD 四个方向**
4. 重要物件标注锚点位置
5. 附上缩略图预览
