# MADMEN — GameJam 开发计划

> **团队分工**：
> - **程序组（4人 + AI辅助）**：新街 / 长安旧梦 / 池言いく / 🙃
> - **美术组（2人）**：霸凌蔬菜 / Tristan
>
> **核心矛盾说明**：
> - 程序组使用 AI 辅助可快速出模块，但 AI 生成代码需要 review、对接、bug 修复
> - 美术组资源产出速度远低于程序组模块化速度
> - 因此美术采用**白盒先行 + 后置替换**策略：程序阶段用占位白盒，美术资源分批交付

## 程序模块总表

| 模块 | 子模块 | 说明 |

| | 抛锚与修车 | 抛锚 → 长按Q修车 → 10s倒计时 |
| | 职责互换 | 躲藏点内互换驾驶/射击职责 |
| **敌人系统** | 弹幕无人机 l1 | 低空飞行，弹幕攻击 |
| | 治疗无人机 l1 | 无攻击，治疗范围逻辑 |
| | 激光无人机 l2 | 横向激光柱，持续伤害区 |
| | 导弹 l2 | 飞行轨迹，落点爆炸 |
| | 对冲摩托车 l3 | 高速正面冲击，附带弹幕 |
| | 敌人刷新节奏 | 按难度曲线动态调度 |
| **BOSS系统** | 第一阶段 | 100%–60%，单一弹幕 |
| | 第二阶段 | 60%–30%，弹幕加强 + 肘击地面 |
| | 第三阶段 | 30%–0%，全弹幕 + 肘击 + 踩地板 |
| **路面障碍** | 障碍生成配置 | 路坑/路障/大型路障的出现频率和位置 |
| | 碰撞响应 | 路坑=死亡 / 路障=15% / 大型路障=30% |
| | 障碍密度曲线 | 路段1低频 → 路段3高频 |
| **技能系统** | 耐力恢复 | 长按消耗20能量，加速耐力回复 |
| | 能量护盾 | 消耗25能量，生成临时护盾抵挡伤害 |
| | 电子干扰 | 消耗20能量，干扰周围敌人使攻击失效 |
| | 维修无人机 | 消耗25能量，召唤无人机自动回血 |
| | 攻击无人机 | 消耗35能量，召唤无人机自动攻击周围敌人 |
| **追兵系统** | 追兵距离管理 | 追兵与机车保持初始距离，持续逼近 |
| | 距离指示箭头 | 红箭头指示追兵与机车距离，修车时越久越红 |
| | 追兵追上触发 | 抛锚10s内未修好 → 警车底部出现 → 游戏结束 |
| **里世界预警** | 切换预警 | 屏幕边缘闪烁边框，提前2s提示 |
| | 切换警报音效 | 预警时触发音效 |
| | 切换瞬间 | 画面短暂黑闪 + 色彩反转过渡动画（0.3s） |
| **抛锚特殊机制** | 抛锚触发 | 血量归零 → 机车停止 → 进入修车状态 |
| | 修车充能 | 驾驶员长按Q持续充能修车（理想5秒修好） |
| | 充能干扰 | 无人机靠近接触充能条会降低进度 |
| | 抛锚效果 | 爆炸清空弹幕、枪手展开护盾 |
| **经济与成长** | 掉落系统 | 金币/能量球/熟练度掉落 |
| | 熟练度积累 | 积累 → 升级 → 加点（每技能最多3级） |
| | 商店系统 | 购买武器/配件/弹药/消耗品 |
| **UI系统** | HUD | 血条/能量条/耐力条/金币/熟练度显示 |
| | 商店界面 | 商品陈列、购买流程 |
| | 开始/死亡/通关画面 | 各游戏状态界面 |
| | 里世界状态指示 | 屏幕边框/色调提示当前世界 |
| **碰撞检测** | 子弹 ↔ 无人机 | 伤害判定、弹药类型叠加生效 |
| | 障碍 ↔ 机车 | 路况碰撞响应 |
| | 弹幕 ↔ 机车 | 机车受伤判定 |
| **屏幕与反馈** | 受伤效果 | 红色边缘闪烁，血条抖动 |
| | 低血量警报 | 屏幕脉动 + 模糊（≤30%触发） |
| | 里世界转场 | 色彩反转过渡动画 |
| | 后处理 | Bloom / 景深 / 受伤色差 |
| **音效系统** | 射击/命中/爆炸音效 | 各武器独立音效 |
| | 环境音效 | 废土风声 / 沃土鸟鸣 |
| | BOSS咆哮/BGM | 背景音乐与切换 |
| **特效系统** | 粒子系统 | 命中/爆炸/弹幕拖尾粒子 |
| | 屏幕震动 | Boss踩地板/技能释放触发 |
| **性能优化** | 对象池系统 | 子弹/敌人/粒子的高效复用 |
| | 帧率稳定性 | 目标60fps |
