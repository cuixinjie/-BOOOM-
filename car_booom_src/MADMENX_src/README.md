# MADMEN - 双人合作弹幕射击游戏

![Godot 4.x](https://img.shields.io/badge/Godot-4.x-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## 项目简介

**MADMEN** 是一款双人合作弹幕射击游戏，两名玩家分别扮演驾驶员和射击手，共同驾驶机车穿越敌人弹幕。

### 核心玩法

- **驾驶员 (P1)**：驾驶机车躲避路面障碍，释放机车技能
- **射击手 (P2)**：控制射击角度，击落空中无人机和弹幕

## 快速开始

### 环境要求

- Godot 4.3 或更高版本
- 支持 GL Compatibility 渲染

### 运行项目

1. 克隆仓库
2. 用 Godot 4.x 打开项目
3. 点击运行即可

## 项目结构

```
MADMEN/
├── project.godot          # Godot 项目配置
├── assets/                # 静态资源
│   ├── art/              # 美术资源
│   ├── audio/            # 音频资源
│   ├── fonts/            # 字体
│   └── configs/          # JSON 配置文件
├── scenes/                # 场景文件 (.tscn)
├── scripts/               # 脚本文件
│   ├── autoload/         # 单例（全局管理器）
│   ├── core/             # 核心系统
│   ├── entities/         # 实体脚本
│   ├── systems/          # 游戏系统
│   ├── ui/              # UI 脚本
│   └── utils/            # 工具类
└── tests/                # 单元测试
```

## 架构设计

项目采用分层架构：

```
┌──────────────────────────────────────────┐
│           Autoload（单例层）               │  可访问：Autoload, Core
├──────────────────────────────────────────┤
│           Core（核心层）                   │  可访问：Autoload, Core
├──────────────────────────────────────────┤
│           Systems（系统层）                │  可访问：Autoload, Core, Systems
├──────────────────────────────────────────┤
│           Entities（实体层）               │  可访问：Autoload, Core
├──────────────────────────────────────────┤
│           UI（界面层）                     │  可访问：Autoload, Core
└──────────────────────────────────────────┘
```

详细设计请参阅 [架构设计文档](./设计文档/游戏架构设计文档.md)。
