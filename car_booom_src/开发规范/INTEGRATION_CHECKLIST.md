## 第一部分：模块接口清单与验证方法

---

### 1. InputManager（池言いく）

| 接口 | 返回值 | 验证方法 |
|:-----|:-------|:---------|
| `get_driver_input()` | `DriverInputData` | 打印返回值，WASD 各方向值是否正确 |
| `get_shooter_input()` | `ShooterInputData` | 打印返回值，方向键和鼠标状态是否正确 |
| `get_mouse_position()` | `Vector2` | 鼠标移动时坐标是否实时更新 |

---

### 2. DamageSystem（长安旧梦）

| 接口 | 参数 | 验证方法 |
|:-----|:-----|:---------|
| `calculate_damage(base, modifier)` | float | 单元测试：相同输入必有相同输出 |
| `apply_damage(target, info)` | void | 对目标发射信号，验证伤害被正确应用 |
| `is_invulnerable(target)` | bool | 里世界切换后验证无敌状态是否正确反转 |

---

### 3. BulletFactory（长安旧梦）

| 接口 | 参数 | 验证方法 |
|:-----|:-----|:---------|
| `create_player_bullet(weapon, pos, dir, ammo)` | Node | 验证子弹方向、速度、弹药类型效果 |
| `create_enemy_bullet(type, pos, dir)` | Node | 验证弹幕类型、伤害值 |
| `apply_ammo_effect(bullet, type)` | void | 各弹药类型效果逐一验证 |

---

### 4. SpawnSystem（长安旧梦）

| 接口 | 参数 | 验证方法 |
|:-----|:-----|:---------|
| `spawn_enemy(type, position)` | Node | 验证敌人类型、位置、无敌状态 |
| `set_difficulty_curve(progress)` | void | 验证不同难度下敌人生成数量和类型 |
| `clear_all_enemies()` | void | 抛锚时清空，验证屏幕上敌人和弹幕全部消失 |

---

### 5. WorldStateSystem（长安旧梦）

| 接口 | 参数 | 验证方法 |
|:-----|:-----|:---------|
| `get_current_world()` | `WorldState` | 切换前后验证返回值变化 |
| `invert_shield_states()` | void | 切换后验证所有敌人无敌状态反转 |
| `swap_player_roles()` | void | 互换后验证装备数据是否正确迁移 |

---

### 6. Driver（池言いく）

### 7. Shooter（池言いく）

| `get_ammo_in_magazine()` | int | 与 HUD 显示值对比，必须一致 |
| `deploy_shield()` | void | 抛锚时验证护盾展开 |

### 8. VehicleSkills（池言いく）

## 第二部分：跨模块集成检查

---

### 检查项 1：信号链路验证

完整跑通一个事件的生命周期：

| 事件 | 链路 | 验证点 |
|:-----|:-----|:-------|
| **敌人被击杀** | BulletPlayer 命中 → DamageSystem 计算 → EnemyBase 扣血 → 血量归零 → DropSystem 掉落 → enemy_killed 信号 → HUD 更新 + EconomySystem 加金币 | 全链路打通 |
| **机车受伤** | 弹幕命中机车 → DamageSystem 计算 → VehicleController 扣血 → vehicle_damaged 信号 → DriverHUD 更新血量 → 如果血量归零 → BreakdownRecovery 触发 | 全链路打通 |
| **里世界切换** | 定时器触发 → WorldStateSystem.invert_shield_states() → 所有敌人护盾反转 → world_state_changed 信号 → LevelManager 切换背景 → AudioManager 切换环境音 → WorldStateIndicator 更新 | 全链路打通 |
| **武器射击** | Shooter.fire() → WeaponBase 发射 → BulletFactory 创建子弹 → EventBus.weapon_fired → ShooterHUD 更新弹药数 → 命中 → DamageSystem 计算 → enemy_killed → 循环 | 全链路打通 |

---

### 检查项 2：边界条件检查

| 场景 | 预期行为 |
|:-----|:---------|
| 弹药打空时射击 | 提示"弹药不足"（或自动换弹），不发射子弹 |
| 能量不足时使用技能 | 技能不触发，提示"能量不足" |
| 耐力耗尽时冲刺 | 冲刺不触发，Shift 键无效 |
| 里世界切换瞬间死亡 | 死亡判定优先于切换 |
| BOSS 战中切换里世界 | BOSS 阶段和无敌状态同时翻转 |
| 抛锚时无人机攻击充能条 | 充能进度正确回退 |
| 护盾被打破后立即再触发 | 有 2 秒冷却，2 秒内无法再次展开 |

---

### 检查项 3：数值一致性检查

| 数据 | 验证 |
|:-----|:-----|
| `weapon_stats.json` 中伤害值 | 与 WeaponBase 代码中使用的数值完全一致 |
| `enemy_stats.json` 中血量值 | 与 EnemyBase 代码中使用的数值完全一致 |
| 霰弹枪散射角度（策划案 45°） | 代码中角度配置必须为 45° |
| 霰弹枪每发伤害（策划案 5×5） | 代码中每发伤害必须为 5 |
| 狙击枪射击间隔（策划案 1s） | 代码中间隔必须为 1.0 秒 |
| 能量消耗（耐力恢复 20/护盾 25/干扰 20/维修 25/攻击 35） | 与 VehicleSkills.gd 中的数值一致 |
| 追兵超时（策划案 10s） | BreakdownRecovery.gd 中倒计时必须为 10.0 秒 |

---

### 检查项 4：依赖层级检查

| 违反规则 | 代码示例（禁止） | 正确做法 |
|:---------|:----------------|:---------|
| System 访问 Entity | `SpawnSystem` 直接调用 `Driver.gd` 的方法 | 通过 EventBus 信号 |
| Entity 访问 UI | `EnemyBase` 直接修改 `DriverHUD` 的血条 | 通过 EventBus 信号 |
| UI 访问 System | `ShopUI` 直接修改 `SpawnSystem` 的敌人生成节奏 | 通过 EventBus 信号 |
| 跨层直接引用 | `WeaponBase` 中 `get_node("/root/SpawnSystem")` | 通过 EventBus 或依赖注入 |
